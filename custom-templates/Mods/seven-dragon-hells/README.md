# 七层世界生成器

1.0.0 · Windows 测试版 · 2026-09-26

生成 **256×256、七层**的随机世界。红色玩家独占第一层，七个电脑分散在其余六层；22对双向界门连接七层，每层可以直接前往另外六层。保留道路、资源和深层守卫梯度，电脑之后也可以通过界门进入玩家所在层。

这是通用世界模板，不再要求龙族模组，也不要求万世天朝。安装万世天朝后可以一起使用。无需 Python、PowerShell、地图收尾工具或原始制作工程。

## 安装与开始

1. 安装 VCMI 并导入自己拥有的英雄无敌3 Complete / Shadow of Death 数据。先确认原版能正常开局。[官方安装说明](https://vcmi.eu/players/Installation_Windows/)
2. 退出游戏和启动器，将压缩包里的 `seven-dragon-hells` 文件夹放入你实际使用的 VCMI 用户数据目录的 `Mods` 下。最终应为 `Mods/seven-dragon-hells/mod.json`；不要改文件夹名或再多套一层。
3. 启用“七层世界生成器”，进入新游戏的随机地图设置，选择 **`Seven Worlds (256x256x7)`**。
4. 使用 **256×256、7层、8方**；红色由玩家控制，其余七方由电脑控制。若界面区分普通席位和电脑专用席位，设1个普通席位、7个电脑席位。
5. **七个电脑的阵营保持随机**；自己的阵营可以选择震旦或其他已启用城镇。直接生成并开始游戏。

本包不含 VCMI 引擎、原版游戏数据、WoG 或任何龙族素材。只使用本生成器不需要 WoG；与万世天朝同玩时，另按万世天朝说明安装它的前置。

## 版本与范围

实际验证：Windows 上的官方 2026-09-08 开发构建 **`1.8.0.0c8650a24ac0e6f196b0b59b2f0fb8e65760157d`**。模组声明兼容1.8.0—1.8.99，但其他构建和设备尚未验收，不能仅凭显示“1.8”判断相同。引擎下载入口：[VCMI 官方下载](https://vcmi.eu/download/)。本次没有修改或升级引擎。

电脑阵营随机是当前引擎保持分层的必要条件。指定电脑阵营会触发地形偏好，可能破坏分层；其他玩家颜色、多人和联机不在本版验证范围。第三至第七层的主题先后可以随机变化。

已验证两个独立种子均能原生生成、通过七层通行与出生分布检查并进入首回合。其中一个种子的酒馆出现“本阵营英雄不足，改选其他英雄”的引擎替补提示；未把它记为零错误通过。尚未穷举所有种子或验证整局AI、长期平衡和全部设备。

推荐从随机游戏直接开始。开发辅助工具导出的原始地图存在席位标记差异，本包不提供这类开发地图，也不要求玩家处理它们。

## 更新旧版

原“七层龙域”0.2.x 用户：先退出游戏，保存旧存档；把旧模组移出 `Mods` 后再安装本包，不要直接混合覆盖遗留文件。本版仍使用内部ID `seven-dragon-hells`，但旧固定地图和两种主题龙群模板已退出玩家包。旧存档不自动变成新版世界，旧存档仍可能需要其原有龙族等前置。请新开随机游戏体验本版。

原创模板和配置沿用随附 MIT 许可；界门图像由玩家自己的原版游戏数据提供，不包含在包内。
